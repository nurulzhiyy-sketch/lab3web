# Praktikum 3: CSS Dasar

## 1. CSS Internal

CSS internal digunakan untuk mengatur tampilan halaman melalui tag `<style>` pada bagian `<head>`, seperti jenis huruf, ukuran judul, warna, dan posisi teks.

![Hasil CSS Internal](<css_internal%202.png>)

## 2. Inline CSS

Inline CSS ditambahkan langsung pada elemen HTML menggunakan atribut `style` untuk mengatur tampilan paragraf.

![Hasil Inline CSS](<css_internal_3%20lanjutan.png>)

## 3. CSS Eksternal

CSS eksternal dibuat dalam file terpisah bernama `style_eksternal.css`, kemudian dihubungkan ke dokumen HTML. Pada hasil praktikum, menu navigasi ditampilkan dengan latar hijau dan tulisan putih.

![Hasil CSS Eksternal](<css_eksternal%204.png>)

## 4. ID dan Class Selector

ID Selector `#intro` digunakan untuk mengatur bagian intro, sedangkan Class Selector digunakan untuk mengatur tampilan tombol.

![Hasil ID dan Class Selector](<class_selector%205.png>)

## Kesimpulan

CSS membantu mengatur tampilan halaman web, mulai dari warna, ukuran teks, posisi elemen, hingga latar belakang. CSS dapat diterapkan menggunakan metode internal, inline, dan eksternal.
